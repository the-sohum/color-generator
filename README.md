# Color Palette Generator 🎨

A sleek, modern, and responsive web application that generates random color palettes. Built purely with semantic **HTML5**, modern **CSS3 (Grid & Custom Properties)**, and **Vanilla JavaScript**. This project focuses on clean code principles without relying on external libraries, frameworks, or complex APIs.

This project is perfectly optimized for both mobile and desktop screens and includes features like color locking, clipboard copy utilities, and local-storage-backed dark mode.

---

## ✨ Features

*   **Instant Palette Generation:** Generate 5 random, harmonious HEX colors instantly with a single button click.
*   **Color Locking System:** Lock individual color cards so they remain unchanged when generating a new palette.
*   **One-Click Copy:** Click the copy button on any card to save the HEX code straight to your clipboard, complete with temporary visual UI feedback (`Copied!`).
*   **Dark/Light Theme Toggle:** Seamless theme switcher that remembers your preference across page refreshes using browser `localStorage`.
*   **Fully Responsive Design:** A custom CSS Grid layout fluidly morphs from a 5-column layout on desktop to 3 columns on tablets, and a clean single-column card stack on mobile.
